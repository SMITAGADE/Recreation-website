# Recreation-website

Recreated the official FinIQ website using Wix Studio and Spline to gain hands-on experience in modern no-code/low-code web development and interactive 3D design. The project focuses on building a visually appealing and fully responsive website with smooth navigation, structured sections (Home, Careers, Services, and Contact), and immersive 3D elements created using Spline. This project demonstrates strong UI/UX understanding, creativity in web design, and the ability to recreate a real-world company website using modern design tools and deployment platforms.
